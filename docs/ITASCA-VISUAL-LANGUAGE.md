# Itasca visual language

The suite's shared visual, icon and motion grammar has one copy, kept in Kadunce:
[`kadunce/docs/ITASCA-VISUAL-LANGUAGE.md`](https://github.com/carlsonjm/kadunce/blob/main/docs/ITASCA-VISUAL-LANGUAGE.md).
Temperance follows it. Its protected exceptions include the animated Bell and the
Weather glyph.

This file stays so that links into it keep working. Change the shared grammar in
Kadunce, not here.
